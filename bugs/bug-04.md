# BUG-01: Ном устгах үйлдэл амжилттай боловч буруу мессеж харагдах

Орчин: node app.js-ийг шинээр асаасан (анхны 3 ном)

Дахин гаргах алхам
1. Браузераар http://localhost:3000 хаягаар орох.
2. Жагсаалтаас дурын номын ард байрлах ногоон "Устгах" товчийг дарж устгах.
3. Дэлгэцийн голд гарч ирэх мессежийг шалгах.

Хүлээгдэж байсан: Үйлдэл бүрийн мессеж тухайн үйлдэлдээ тохирсон байх (жишээ нь: ном устгахад устгагдсан тухай мессеж гарах).
Бодит үр дүн:     Ном хүснэгтээс амжилттай устгагдаж байгаа боловч мессеж хэсэгт "Ном нэмэгдлээ" гэж буруу гарч байна.

Ноцтой байдал: Minor / Cosmetic — Хэрэглэгчийг төөрөгдүүлж болзошгүй UI мессежийн алдаа.
