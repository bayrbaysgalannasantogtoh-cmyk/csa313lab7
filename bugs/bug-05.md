BUG-05: API хүсэлт буруу форматтай байхад сервер Bad Request оронд 200 OK буцаах

Орчин: node app.js ажиллаж байгаа

Дахин гаргах алхам
1. Ubuntu терминал дээр дараах curl командыг ажиллуулах:
   `curl -i -X POST localhost:3000/api/books -d 'буруу оролт'`
2. Серверээс буцаж буй HTTP статус код болон хариуг шалгах.

Хүлээгдэж байсан: Сервер рүү буруу эсвэл дутуу форматтай JSON өгөгдөл POST хийхэд сервер алдааг таньж `Bad Request` статус код буцаах ёстой.
Бодит үр дүн:     Сервер нь ямар нэгэн шалгалт хийлгүйгээр `200 OK` болон `result: 'OK'` гэсэн хариу буцааж байна.

Ноцтой байдал: Major — API түвшинд оролтын баталгаажуулалт (validation) дутуу байгаа нь өгөгдлийн бүрэн бүтэн байдалд сөргөөр нөлөөлөх.
