Хэсэг E — Дүгнэлт

Энэхүү лабораторийн ажлын хүрээнд Уншлагын жагсаалт вэб аппликейшнд хар хайрцгийн болон эксплоратори тестийн аргуудыг ашиглан туршилт хийлээ. Туршилт явуулах явцад Supermodel буюу GUI интерфейс болон Saboteur буюу API түвшний аялалуудыг хослуулан ашигласан нь маш үр дүнтэй. Тухайлбал, интерфейсийн болон хэрэглэгчийн алдаанууд GUI аялалаар илэрсэн бол өгөгдлийн баталгаажуулалт болон сервер талын хариу төлөвийн зөрдөг асуудлууд API түвшний curl туршилтаар тодорхой харагдсан.

Charter буюу төлөвлөгөөний дагуу шалгахаас гадна системтэйгээр нэг бүрчлэн ажиллахад зориудаар суулгасан олон төрлийн жижиг алдаанууд амархан анзаарагдсан. Гэхдээ зарим нарийн утга шалгах хязгаарлалтууд болон хүснэгтийн тооцооллын алдаа зэрэг нь зөвхөн анхааралтай ажиглалт болон өгөгдлийн харьцуулалтаар л олдохоор байсан.

Эдгээр олдсон согогуудын зарим нь тухайлбал товчны хариу үйлдэл болон интерфэйсийн мессежийн зөрүүг Playwright зэрэг автомат тестээр хялбархан барих боломжтой байсан. Харин системийн ерөнхий хэрэглэгчийн туршлага, мессежний тохиромжтой байдал болон хүний нүдээр харахад шууд анзаарагдах утгын жижиг алдаануудыг зөвхөн хүний нүдээр тест хийж байж л чанартай илрүүлэх боломжтой юм байна.
